# HOMECHECK LAB (홈체크 랩) - 신축 아파트 정밀 하자점검 쇼케이스

> 신축 아파트 사전점검 서비스의 반응형 웹(메인 랜딩 + 3단계 온라인 예약 접수 폼) 공식 쇼케이스 프로토타입입니다.

## 주요 기능
- **메인 랜딩**: FLIR 열화상, BOSCH 그린레이저, 라돈아이, 배관내시경 4대 전문 장비 소개, 실제 하자 유형 4종 비교 뷰, 4단계 점검 프로세스, 투명한 정찰제 가격표, FAQ
- **온라인 예약 접수 화면 (인터랙티브 폼)**: 단지명/동호수/희망일시 입력, 평형 및 부가옵션 선택 시 실시간 예상 견적 자동 산출, 예약 신청 접수 인터랙션 모달
- **기술 스택**: HTML5, Tailwind CSS, Lucide Icons, Pretendard 웹폰트, Vercel Edge 배포
